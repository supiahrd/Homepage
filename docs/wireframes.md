# 와이어프레임 (저해상도 레이아웃)

실제 디자인(색상/폰트)은 2단계에서 정하고, 여기서는 각 페이지 유형의 정보 배치만 정의한다.

## 공통 레이아웃

```
┌─────────────────────────────────────────────┐
│ [로고]   Home Services Projects About Contact│ ← 헤더(고정, 전 페이지 공통)
├─────────────────────────────────────────────┤
│                                               │
│                (페이지별 본문)                │
│                                               │
├─────────────────────────────────────────────┤
│ 회사명 / 주소 / 연락처   |  소셜링크          │ ← 푸터(공통)
└─────────────────────────────────────────────┘
```

## Home

```
[Hero] 대표 이미지(숲) + 헤드라인 + 서브카피 + CTA버튼(문의하기)
[회사 특장점] 3~4개 아이콘+텍스트 카드 (조직생태학 방법론 요약)
[주요 서비스] 서비스 3종 카드 (제목+한줄설명+더보기 → /services/{slug})
[주요 사례] 대표사례(is_featured=1) 3~4개 카드 (고객사명+프로그램명 → /projects/{slug})
[문의 유도 배너] 간단 문구 + Contact 링크/버튼
```

## Services 목록 (`/services/`)

```
[페이지 헤더] "Services" + 한줄 소개
[3개 카드 그리드] 리더십 개발 / 팀빌딩·조직활성화 / 임직원 힐링
   각 카드: 아이콘 or 이미지, 제목, 요약, "자세히 보기" 링크
```

## Service 상세 (`/services/{slug}`)

```
[페이지 헤더] 서비스명 + 부제
[본문] description (관리자가 입력한 상세 설명)
[관련 사례] 같은 category의 projects 카드 목록 (있는 경우)
[CTA] Contact 유도
```

## Projects 목록 (`/projects/`)

```
[페이지 헤더] "Projects" + 한줄 소개
[카테고리 필터] 전체 / 리더십 / 팀빌딩·조직활성화 / 힐링
[카드 그리드] 사례 6건: 고객사명, 프로그램 타이틀, 요약, 대표이미지 → 상세 링크
```

## Project 상세 (`/projects/{slug}`)

```
[페이지 헤더] 고객사명 + 프로그램 타이틀
[대표 이미지]
[본문] summary → description(상세) → results_text(성과/후기)
[이전/다음 사례 이동] (선택)
[CTA] Contact 유도
```

## About (`/about`)

```
[페이지 헤더] "About us"
[조직생태학 방법론] about_sections(section_key='methodology')
[창립자 소개] about_sections(section_key='founder') + 사진
[연혁 타임라인] history_entries를 연도순 세로 타임라인으로 표시
```

## Contact (`/contact`)

```
[좌] 연락처 정보: 주소, 전화, 이메일, 지도(선택) — site_settings 값
[우] 문의 폼: 이름, 이메일, 전화(선택), 메시지, 제출버튼
[제출 후] 완료 메시지 표시, contact_messages 테이블에 저장
```

## Admin 공통 레이아웃

```
┌───────────────────────────────────────────┐
│ [사이드바]           │   [본문 영역]        │
│ - 대시보드            │  목록형 화면:        │
│ - 서비스 관리         │   테이블(제목/정렬/  │
│ - 프로젝트 관리       │   수정/삭제 버튼)    │
│ - About 관리          │  + "새로 추가" 버튼  │
│ - 사이트 설정         │                     │
│ - 문의 내역           │  편집형 화면:        │
│ - 로그아웃            │   폼(필드별 input,   │
│                       │   textarea, 이미지  │
│                       │   업로드, 저장버튼)  │
└───────────────────────────────────────────┘
```

## 로그인 (`/admin/login.php`)

```
[중앙 카드] 로고 + 아이디 입력 + 비밀번호 입력 + 로그인 버튼
```

---

## 확인 필요 (2단계 진행 전)

- **이미지 소스**: 숲/유기적 생명공동체, 지의류(상리공생) 은유를 표현할 이미지를 무료 스톡에서 고를지, 보유하신 사진/자료가 있는지
- **Projects 개수**: `sitemap.md`에 남긴 6건 vs 7건 불일치 확인
